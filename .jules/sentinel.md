## 2026-05-18 - [Missing escapeHTML function]
**Vulnerability:** XSS vulnerability through lack of input sanitization
**Learning:** We need to sanitize user input when generating dynamic HTML directly in client-side code to prevent Cross-Site Scripting (XSS).
**Prevention:** Implement and use an escapeHTML function to sanitize text input before inserting it into innerHTML.

## 2025-02-28 - [Unescaped LLM Output in innerHTML]
**Vulnerability:** XSS vulnerability through lack of input sanitization of LLM outputs (e.g. `data.persona`, `data.quote`, `data.emoji`) injected into `index.html` via `innerHTML`.
**Learning:** Relying solely on JSON structure parsing does not prevent malicious script injections in vanilla JS frontends. Fields generated by LLMs must still be explicitly sanitized before being rendered to the DOM.
**Prevention:** Always use the `escapeHTML` function to explicitly sanitize LLM-generated string values before interpolating them into HTML templates.
