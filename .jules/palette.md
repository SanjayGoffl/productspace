## 2024-05-24 - Accessibility Insights on Form Labels and Icon-only Buttons
**Learning:** Found that `<label>` elements were missing explicit `for` attribute linkages to form inputs, and several icon-only buttons lacked `aria-label`s, which creates a poor experience for screen reader users. I also discovered that `aria-hidden="true"` needs to be added to decorative font-awesome icons (`<i>`) inside buttons to prevent screen readers from reading them incorrectly. This applied to both static HTML and dynamically generated JS strings.
**Action:** Always ensure that form inputs have correctly associated labels using the `for` attribute. Add descriptive `aria-label`s to all icon-only buttons and hide their decorative inner icons using `aria-hidden="true"`. Double-check dynamic HTML template literals in JS for these accessibility attributes.
