## 2024-06-25 - Enhance Accessibility in Forms and Icon Buttons

**Learning:** It's important to associate labels with inputs using the `for` attribute and ensure icon-only buttons have descriptive `aria-label`s. In a vanilla HTML file like `index.html`, this is mostly done manually by inspecting the markup.
**Action:** Always check form structures and standalone interactive elements for proper ARIA/accessibility attributes when introducing or modifying UI elements.
